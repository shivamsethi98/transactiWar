Phase-1: This is a group project (up to 5 members) that aims to help you understand the principles of web application security. You need to design a secure web application that implements the functionality described in each task. 
Technologies allowed: 
Front-end: HTML/CSS/JS/Bootstrap
Back-end: PHP  + MySQL/PostgreSQL

Note: YOU CANNOT USE ANY IN-BUILD FRAMEWORKS THAT PROVIDE ANY SECURITY TO IMPLEMENT ANY OF THE TASKS. 
If required, design or write your own framework. You can use cryptography libraries if needed. 
Please note that we will use the Docker environment to host or evaluate your project. Therefore, ensure that your programming platform is compatible with the Docker environment and provide the necessary scripts to build the Docker image. Submissions that fail to provide such a provision will receive zero marks. (See Deliverables 1)
Web Application Specifications             	                        [100 Marks]
User Authentication & Session Management
User Registration:
Users register with a unique username, email, and password.
Each new user is credited with Rs. 100.
Login & Logout
Session Management
Profile Management
Users can update personal details (except usernames).
Ability to upload and store long content (e.g., biography).
Ability to upload a profile image (with secure storage).
Ability to see other users' profiles.
User Search & Money Transfer
Search Users: Search by username or user ID.
Money Transfer:
Transfer money to another user by user ID.
Prevent negative balance transactions.
Display transaction history.
Comments
Users can put an optional comment along with the money transfer
The comment should be visible to the receiver
You must log user activity, inclusive of <Webpage, Username, Timestamp, Client’s IP Address>
Docker Script to run your application inside the container (so automatic configuration is needed).
